# Cubbl marketing assets — English

- `cubbl-icon-512.png`: 512 × 512 PNG, exported from the existing icon master. Use for the Play Store app icon.
- `feature/feature-01.png`: 1024 × 500 PNG, sunset campaign, “Stack high. Stay steady.”
- `feature/feature-02.png`: 1024 × 500 PNG, daytime campaign, “One more perfect drop.”
- `phone/phone-01.png`: 1080 × 1920 PNG, gameplay, “Stack high. Stay steady.”
- `phone/phone-02.png`: 1080 × 1920 PNG, streak, “Make it perfect.”
- `phone/phone-03.png`: 1080 × 1920 PNG, home screen, “Your next tower awaits.”
- `phone/phone-04.png`: 1080 × 1920 PNG, game over, “Chase your best.”

Choose one feature graphic for the main store listing; the other is an alternative for future campaigns or listing experiments. Phone images are ordered as a suggested marketing sequence.

The feature graphics and phone posters were made with the built-in image_gen tool using the existing Cubbl icon and screenshots as references. Phone screens are AI-recomposed marketing mockups, not pixel-identical screen captures. Original screen captures remain in `docs/screenshots/readme/`; use actual captures when exact gameplay fidelity is needed. No app code or original screenshots were changed.

## Prompt set

Shared direction: pastel low-poly city matching Cubbl; cream, sage, terracotta and forest green; friendly rounded English typography; no store badges, ratings, awards, prices or unsupported claims.

1. Feature sunset: landscape city and precarious house tower; title “Cubbl”; headline “Stack high. Stay steady.”; no phone or HUD. References: gameplay screenshot and icon master.
2. Feature daytime: blue sky, canal city, crane-suspended teal house above a pastel tower; title “Cubbl”; headline “One more perfect drop.”; no phone or HUD. Same references.
3. Phone gameplay: front-facing unbranded thin-bezel Android mockup, gameplay screenshot as screen reference, cream backdrop, “Stack high. Stay steady.” and “Every drop matters.”
4. Phone streak: same mockup direction, streak screenshot as screen reference, pale sage backdrop, “Make it perfect.” and “Build your streak.”
5. Phone home: same mockup direction, home screenshot as screen reference, pale peach backdrop, “Your next tower awaits.” and “Start stacking with Cubbl.”
6. Phone game over: same mockup direction, game-over screenshot as screen reference, sky-blue backdrop, “Chase your best.” and “One more try. One higher tower.”

## Export verification

PNG dimensions and color types are checked before packaging. Generated originals remain in the Codex generated-images directory; resized exports are included here. The icon is below 1024 KB. Feature graphics and phone posters have no alpha channel.
